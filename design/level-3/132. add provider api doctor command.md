# Add provider API doctor command

## Objective

Add `srig doctor` to resolve the active provider configuration, apply the live
credential authorization path, and send a bounded request that verifies the
model ends its response with `MODEL OK`.

## Completion checklist

- [x] CLI exposes human and JSON doctor reports.
- [x] Doctor resolves the same layered settings and credential policy as `run`.
- [x] Doctor sends a minimal request through the OpenAI-compatible provider.
- [x] Doctor accepts brief reasoning before the final `MODEL OK` marker.
- [x] Output reports safe configuration, credential, and API status without
  displaying the response or credential value.
- [x] Tests cover request bounds, result classification, parser, and live API
  transport/auth behavior.
- [x] CLI reference documents the request and its effects.
- [x] Relevant formatting, repository lint, tests, and Clippy pass.
