# Implement Branch-Aware Web Agent Experience

**Status: [ ] Pending**

## Objective

Implement reusable browser support for starting and observing the shared branch-aware agent runtime, then compose it into the integrated Scriberig web application.

Read first:

1. `design/level-1/012. web platform and integrated editor.md`;
2. `design/level-1/016. model driven agent execution and branch isolation.md`;
3. `design/level-2/017. web workspace packages and integrated editor.md`;
4. `design/level-2/024. agent operations protocol and cross surface product contract.md`;
5. `design/level-3/111. expose agent execution through application protocol server and clients.md`.

The controlling rule is:

> The browser talks only to the public Scriberig client/protocol. It never contacts the model provider and never stores provider credentials.

The existing `@scriberig/agent-ui` package is the reusable React agent/session presentation layer. Do not implement the complete behavior only inside `web/apps/scriberig`.

## HTTP and Event Stream

Use the existing `http-transport.ts` and `event-stream.ts` boundaries rather than adding a second agent-specific network stack.

Agent event subscription must support:

```text
operation/session correlation
monotonic event cursor/sequence
clean close/reconnect
error state
resume cursor when server supports replay
fallback authoritative refresh when replay is unavailable
```

A dropped event stream must not lose the final result because operation/session queries remain authoritative.

## Model Package State

Extend `@scriberig/model` with reusable state equivalent to:

```text
AgentWorkspaceState
  sessions
  branchDescriptors
  loadedBranchChildren
  loadedBranchActivityPages
  activeOperations
  transientStreams
  eventCursors
  loading/errors/stale markers
```

Keep these categories distinct:

### Canonical/durable loaded state

Derived from authoritative server session/operation queries:

```text
session descriptor
branch descriptor/tree
branch activity objects
BranchResult
AgentResult
operation terminal state
```

### Transient presentation state

Derived from live events and safe to discard/rebuild:

```text
partial model text
current phase label
optimistic loading marker
latest received event cursor
```

Never merge a `ModelTextDelta` directly into canonical session history.

## Event Reducer

Extend model event reduction with deterministic handling of agent events.

Rules:

- ignore already-applied duplicate sequence numbers;
- do not regress state when an older event arrives after a newer one;
- `BranchCreated` may mark parent-child data stale or insert a bounded descriptor when the event carries authoritative-enough metadata;
- durable-result events should trigger/reference authoritative objects;
- `ModelTextDelta` updates only transient stream buffers;
- `AgentOutputCommitted` clears/replaces the relevant transient stream after authoritative output is loaded;
- terminal operation events cause an operation/result refresh;
- connection loss marks live state disconnected/stale without pretending the operation stopped.

Add focused pure reducer tests.

## Agent Composer

The reusable composer must support:

```text
new-session/root start
continue selected session/branch
multiline prompt
current semantic selection summary
submit disabled/loading state
structured start/continue failures
```

It must not expose provider credentials.

On submit:

1. build the public start/continue request;
2. invoke `@scriberig/client` through model/controller bindings;
3. immediately store returned operation/session/root branch refs;
4. begin operation/event observation;
5. preserve prompt text appropriately on failure.

## Session Branch Tree

Render nested branch descriptors without loading all branch activity.

Each branch row/card should support:

```text
purpose/title
active/completed/abandoned state
compact outcome
child count
activity count
result availability
active-operation marker
expand/collapse
select/navigate
```

Completed branches default to compact collapsed representation.

Expanding a node loads child descriptors on demand.

Do not hard-code a maximum visual nesting depth. Deep trees may use indentation caps plus breadcrumbs/ancestry markers rather than becoming unusable.

---

## Branch Summary Card

A completed child branch shown in its parent flow should render primarily from `BranchResult`/descriptor:

```text
purpose
outcome
status
important result handles
produced change/validation badges
Open branch action
```

It must not require fetching all child turns.

This component is the browser expression of context collapse: result first, provenance expandable.

## Branch Activity

When a branch is opened, render paginated semantic activity:

```text
HumanInput
AgentOutput / ModelOutput
ToolInvocation
ToolResult
child branch/result
Decision/Observation/Summary
Migration/Validation references
```

Tool invocation/result rows default to bounded summaries with explicit expansion or semantic-handle navigation.

Do not render raw provider JSON as the primary user experience.

---

## Streaming Output

Show partial model output from `transientStreams` while an operation is active.

Requirements:

- visibly in-progress;
- keyed to exact operation/branch/invocation;
- discarded/replaced when durable output is committed/loaded;
- never inserted into durable branch activity as a fake message;
- survives component rerenders but need not survive page reload;
- after reload, recover from durable branch/operation state without stream replay.

If the transport cannot resume from the previous event cursor, perform authoritative refresh and continue from the new subscription point.

All semantic result handles must integrate with the existing universal editor navigation.

Examples:

```text

```

`@scriberig/agent-ui` emits semantic navigation intents/uses editor-core public APIs; it does not implement duplicate routing semantics.

## Candidate Change Review

When a branch produces candidate canonical changes:

- show them as result handles/status in agent UI;
- route to existing `MigrationPreview`/validation/review abstractions;
- require normal confirmation/capability flow;
- display stale/conflict/validation failures through shared error/result models.

Do not add an "Accept model output" shortcut that bypasses change semantics.

## Reconnect and Page Reload

Test and implement recovery behavior:

```text
reload/open app
-> restore/select known session or operation ref where product state persists it
-> fetch operation status
-> fetch session/root branch descriptors
-> fetch selected branch activity on demand
-> subscribe from known cursor when supported
```

The exact browser-local persistence of last-open session may remain product-local UI state. It must not become canonical session identity.

The final result must remain visible after reload even if all transient stream fragments were lost.

## Security

Assert at compile/test boundaries that browser types do not contain provider secret fields.

Never add:

```text
apiKey
Authorization provider header
provider secret token
raw provider credential config
```

to public web agent requests.

Safe provider/model display metadata may be shown if the public protocol intentionally exposes it.

Escape/render external/model/tool text as ordinary React text. Do not use raw HTML injection for model output.

---

## Accessibility

Reusable agent UI must support keyboard operation and non-color status communication.

At minimum:

- tree rows/buttons are keyboard focusable;
- expanded/collapsed state is exposed accessibly;
- running/completed/failed states have text labels;
- composer has associated accessible labeling;
- cancellation is identifiable and disabled state explained when practical;
- live progress regions avoid excessively noisy screen-reader announcements for every token delta.

Use throttled/bounded live-region updates for streaming rather than announcing every fragment.

## Tests

Use fake transports and deterministic protocol fixtures. No public model endpoint is allowed.

Cover at least:

### Client/model

- start returns/stores operation/session/root branch refs;
- nested branch descriptors reduce correctly;
- duplicate/out-of-order events do not regress state;
- model text deltas update only transient buffers;
- durable output replaces transient state;
- disconnect/reconnect marks state and refreshes correctly;
- final result survives losing all stream deltas.

### React/agent-ui

- composer includes current universal selection;
- completed branches default collapsed;
- expanding loads children/activity lazily;
- child result handles trigger semantic navigation;
- cancel button obeys capability/lifecycle state;
- nested branch tree keyboard navigation works;
- no raw provider credential field is present;
- model/tool text renders safely as text.

### Integrated app

- SessionAgentView communicates only through public packages;
- a deterministic fake-backed start -> child branch -> final result flow renders end to end;
- produced migration/result can navigate into existing review/semantic views.

Run at least:

```text
pnpm --dir web format
pnpm --dir web typecheck
pnpm --dir web test
pnpm --dir web build
```

Run repository boundary/conformance checks that validate package import direction.

## Do Not Do

- Do not contact the OpenAI-compatible provider from browser code.
- Do not add provider API keys to browser configuration.
- Do not make the web app own a second agent/session store.
- Do not flatten branch trees into a chat-only canonical model.
- Do not treat streamed text as durable branch activity.
- Do not require full child history to render parent branch results.
- Do not bypass universal selection/navigation or migration review.
- Do not put reusable agent behavior only in `web/apps/scriberig`.
