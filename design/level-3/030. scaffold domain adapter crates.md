# Scaffold Domain Adapter Crates

## Objective

Create the first domain-specific Rust crate boundaries required by `design/level-1/007. domain modeling and adapters.md` without implementing domain behavior yet.

This task establishes where Markdown, language-independent code, Rust, and PDF domain logic will live. Session domain logic already belongs in `crates/scriberig-session` and must not be duplicated under `crates/domains/`.

Read before editing:

1. `design/level-1/007. domain modeling and adapters.md`
2. `design/level-2/001. workspace and package layout.md`
3. the current root `Cargo.toml` and existing workspace members

The important rules are:

- domain crates specialize the universal knowledge model;
- domain crates must not introduce their own persistence architecture;
- domain crates must remain usable without the agent runtime;
- adapters depend on shared store/graph/schema/migration/projection layers, never the reverse;
- source-code support uses a language-independent code domain plus language-specific specializations.

## Source File Content

Each new `src/lib.rs` must contain crate-level documentation and no speculative domain implementation yet.

Document these roles accurately:

- `scriberig-domain-markdown`: Markdown semantic schema and adapters for import, rendering, reconciliation, validation, and semantic operations;
- `scriberig-domain-code`: language-independent source-code vocabulary shared only where semantics genuinely overlap;
- `scriberig-domain-rust`: Rust-specific syntax/schema/adapter integration layered on `scriberig-domain-code`;
- `scriberig-domain-pdf`: PDF import and extracted semantic-structure domain, preserving source provenance and geometry.

Include a sentence in every crate-level doc stating that canonical state is stored through the shared universal model and that the crate must not create an independent source of truth.

Do not create placeholder public traits merely to make the crate look complete. Later tasks will add concrete modules once the shared schema APIs exist.
