# Implement Agent Profiles, Branch Handoff Context Components, and Evidence-Driven Prompt Experiments

**Status: [ ] In Progress**

## 1. Objective

Implement the architecture defined by:

- `design/level-1/021. agent profiles context composition and evidence driven optimization.md`;
- `design/level-2/030. agent profile context component and prompt experiment runtime.md`.

Also preserve the controlling contracts from:

- `design/level-1/016. model driven agent execution and branch isolation.md`;
- `design/level-1/017. recursive agent decomposition and context isolation.md`;
- `design/level-1/018. durable plans dependency scheduling and multi-model execution.md`;
- `design/level-1/019. semantic agent operations and projection-first editing.md`;
- `design/level-1/020. provider continuation state and observable model execution.md`;
- `design/level-2/023. agent runtime model provider and branch orchestration.md`;
- `design/level-2/025. provider continuation and observable model execution.md`;
- `design/level-3/135. implement recursive semantic agent plans dependencies and tree tui.md`;
- `design/level-3/136. implement provider continuation full prompt and observable reasoning.md`.

The first visible behavior change is intentionally small:

> Every model invocation receives the Scriberig core behavioral invariants, and every non-root branch receives an additional instruction to make its final response a compact one-paragraph parent handoff. Root branches do not receive that handoff instruction. Existing child completion continues to persist the final child output as `BranchResult.summary`; do not add another summarizer model call.

The complete task then makes those instructions versioned context components, records their exact provenance in effective requests, and establishes evidence-backed prompt experiments without making prompt files canonical state.

Follow phases in order. A simpler implementation agent should not jump directly to an autonomous optimizer.

## Task B2 — Define the bootstrap default profile

Add one deterministic bootstrap profile construction function in the shared agent/runtime layer.

It must contain separate components for:

1. **core Scriberig invariants** — activation `Always`;
2. **non-root branch handoff** — activation `NonRootOnly`.

Core component meaning must include:

```text
operate inside the current Scriberig branch/context frame

```

```text
When about to finish this non-root branch, make the final response a compact
one-paragraph summary for the parent. Include important outcome,
decisions/discoveries, remaining issues, and durable semantic/result handles.
Do not reproduce the branch transcript or hidden reasoning.
```

The exact prose may be polished, but preserve the semantic requirements.

- [ ] Core and handoff are separate components.
- [ ] Profile identity/revision is stable for identical definitions.
- [ ] Component identities/revisions are stable for identical definitions.
- [ ] Changing a component's behaviorally relevant content changes its revision/fingerprint.
- [ ] The bootstrap definition is short; no unrelated domain guidance is added.
