- edit fixture files directly to simulate semantic operations;

- skip validation/review/promotion/materialization in golden edits;
- make web/TUI tests use private application internals unavailable to remote clients;
- require external network/model/provider services for deterministic acceptance;
- make test ordering hide persistent-state/restart defects.
