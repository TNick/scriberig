## 14. Implementation Notes

The existing UI neutral `ConversationModel` remains the source of ordered rows,
stable durable identities, plan placement, branch depth, and reply anchors. The
home renderer uses the task-139 kit for Markdown, safe external text, semantic
branch colors, and the persistent editor while Ratatui remains the single shell
layout, drawing, event, and terminal lifecycle owner.

Shared output events carry an operation ID but no model-invocation ID or
provider sequence. The TUI correlates accepted operations to their stable branch
handles, bounds each transient output to 8,192 sanitized characters, and assigns
a local arrival sequence shared with live activity rows. Complete output
replaces streamed fragments; matching durable assistant text removes the
transient entry after session refresh. This preserves available event ordering
without adding a second canonical transcript or changing shared session data.
