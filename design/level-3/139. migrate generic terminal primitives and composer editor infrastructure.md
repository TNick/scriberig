## 14. Implementation Notes

The pinned upstream crate exposes editor and presentation components but no
general terminal-event normalizer. Scriberig therefore retains its
Crossterm-owned event decoder and action keymap, adding Home, End, and Delete
translations for the shared composer editor. This keeps key help and slash
command ownership in Scriberig while the kit owns editing, safe text and
Markdown rendering, fuzzy selection mechanics, and semantic theme mapping.

The persistent conversation composer now wraps the kit editor; cursor state
remains presentation-only and the existing draft/action submission contract is
preserved. Palette filtering uses the upstream fuzzy selector and returns
stable action IDs after filtering. The old case-insensitive substring helper
was removed after its production path was replaced.

Focused verification passed: 15 tests in `scriberig-tui-kit`, 211 tests in
`scriberig-tui`, `cargo check -p scriberig-tui`, and Clippy for both crates
with warnings denied. Formatting passed with `cargo fmt --all`.
