## Status Vocabulary

Use these states for scaffold tasks:

- **Complete**: applicable completion criteria are implemented and verified.
- **Partial**: material implementation exists but one or more applicable verification/completion criteria remain.
- **Superseded**: later design changed the instructions; the task remains historical but must not guide new implementation.
- **Pending**: material implementation has not started.

When this reconciliation marks a task Superseded, agents must follow the newer Level 2/3 documents rather than trying to restore the obsolete layout.

## Reference Repair Rule

Older scaffold tasks contain stale references created before Level 2/3 filename prefixes were normalized.

When editing any such task, replace stale paths with the current filenames. In particular:

```text
old: design/level-2/001. workspace and package layout.md
new: design/level-2/018. workspace and package layout.md

old: design/level-2/001. web workspace packages and integrated editor.md
new: design/level-2/017. web workspace packages and integrated editor.md

old foundation-task references using 001
new: design/level-3/028. initialize rust foundation workspace.md

old web-headless-task references using 003
new: design/level-3/048. initialize web workspace and headless packages.md
```

Do not infer document identity from an obsolete numeric prefix alone; match by title and current directory contents.
