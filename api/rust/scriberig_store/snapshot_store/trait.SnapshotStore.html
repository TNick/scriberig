fn diff_snapshot_revisions( &self, from: SnapshotId, to: SnapshotId, ) -> Result<Vec<SnapshotDiff>, SnapshotError>

Computes exact entity revision transitions between stored snapshots.

Backends can override this method to compare each retained snapshot in a single read. The default implementation uses deterministic snapshot iteration and keeps before/after revisions available to history callers.

§Parameters
  • from: Starting snapshot identity.
  • to: Ending snapshot identity.
§Returns

Deterministically ordered additions, removals, and revision changes.

§Errors

Returns an error when either snapshot is unavailable.
