1//! Models derived knowledge without changing canonical semantic snapshots.
2//!
3//! Derived results may share storage with canonical knowledge, but do not
4//! participate in snapshot identity unless explicitly promoted through the
5//! canonical change model. Exact reuse is based on declared derivation
6//! dependencies and semantics, not entity identity alone or file timestamps.
7//! Snapshot identity answers whether canonical scope state changed; derivation
8//! keys answer whether a particular result still applies. Completeness claims
9//! such as “all” or “none” need explicit scope dependencies. Freshness and
10//! retention are independent: external observations can become stale for
11//! current requests while remaining historical records, and retention does
12//! not establish validity. This crate has no agent dependency and is useful
13//! to ordinary library consumers. A `SnapshotId` answers whether canonical
14//! scope state changed; a `DerivationKey` answers whether a specific result
15//! still applies. Queries asserting “all”, “none”, or completeness require a
16//! dependency on the relevant scope so newly matching items invalidate the
17//! materialization. None of these derived operations advances snapshots.
