Expand description

Holds plan nodes and a separate acyclic dependency graph.

pub fn replan( &mut self, additions: Vec<PlanNode>, dependencies: Vec<(EntityId, EntityId)>, removed_dependencies: &[(EntityId, EntityId)], superseded: &[(EntityId, EntityId)], assignment_changes: &[(EntityId, Option<ModelAssignment>)], preserved_terminal_nodes: &[EntityId], reason: &str, ) -> Result<(), PlanError>

Applies one validated replan as a single durable revision.

Superseded unfinished work is marked abandoned and linked to its replacement. Completed nodes and their exact results remain intact. Existing dependency edges that touch superseded nodes leave the current projection while remaining inspectable in plan history.

  • self: Paused or failed plan being revised.
  • additions: New structured nodes with already allocated identities.
  • dependencies: Explicit prerequisite/dependent identities to add.
  • superseded: Old-node and replacement-node identity pairs.

Returns MissingNode, InvalidTransition, DependencyCycle, or RevisionExhausted when the proposal is inconsistent.

Successful results fulfill explicit dependency edges. Failed workers release their claims while leaving dependents blocked. The plan becomes complete in the same revision when every required result is present.

  • completed: Exact (node, claim, result) completion records.
  • failed: Exact (node, claim) failed worker claims.
  • available_results: Durable branch results used for plan completion.

Returns a plan error without partial mutation for stale claims, result mismatches, duplicate settlement entries, or revision exhaustion.
