Expand description

Provides semantic execution for the universal application request model.

Required Methods§

Source

fn execute( &self, context: &ApplicationContext, request: &ApplicationRequest, ) -> Result<ApplicationResult, ApplicationError>

Executes one transport-independent application request.

§Parameters
  • self: Backend owning semantic subsystem providers.
  • context: Caller, capability, and request context.
  • request: Universal application request to execute.
§Returns

Structured application result owned by the canonical subsystem.

§Errors

Returns a structured application failure without transport details.

fn current_snapshot( &self, _context: &ApplicationContext, ) -> Result<SnapshotId, ApplicationError>

  • _context: Caller context.

fn update_session_execution_selection( &self, _context: &ApplicationContext, _session: &Session, _expected_revision: u64, ) -> Result<(), ApplicationError>

Atomically persists a session execution selection through its owner.

§Parameters
  • _context: Authorized application context.
  • _session: Session snapshot with the updated selection.
  • _expected_revision: Selection revision observed by the caller; the owner must compare it atomically with the persisted revision.
§Returns

Unit after the update is persisted.

§Errors

Returns conflict for a stale revision, or unsupported-operation when the backend cannot atomically mutate session state.
