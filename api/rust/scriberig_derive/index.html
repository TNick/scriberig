Models derived knowledge without changing canonical semantic snapshots.

Derived results may share storage with canonical knowledge, but do not participate in snapshot identity unless explicitly promoted through the canonical change model. Exact reuse is based on declared derivation dependencies and semantics, not entity identity alone or file timestamps. Snapshot identity answers whether canonical scope state changed; derivation keys answer whether a particular result still applies. Completeness claims such as “all” or “none” need explicit scope dependencies. Freshness and retention are independent: external observations can become stale for current requests while remaining historical records, and retention does not establish validity. This crate has no agent dependency and is useful to ordinary library consumers. A SnapshotId answers whether canonical scope state changed; a DerivationKey answers whether a specific result still applies. Queries asserting “all”, “none”, or completeness require a dependency on the relevant scope so newly matching items invalidate the materialization. None of these derived operations advances snapshots.
