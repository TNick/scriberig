    Migrate Auxiliary Semantic Views, Palette, Review, and Terminal Safety¶

    Status: [x] Complete

    1. Objective¶

    After task 140 completes, migrate the non-home TUI surfaces to the adopted terminal foundation while preserving the semantic view contracts from Level-1/Level-2 TUI design.

    This sheet covers the current equivalents of:

    /session structural view
/explorer or semantic navigation
/inspect
/history
/diff
/projection
/change/review/validation
/operations
/model/profile controls
command palette
help
confirm/input/error overlays
status/diagnostic surfaces

    Exact command names and current view types must be taken from current main.

    The goal is not to make every screen visually identical. The goal is to remove dependency on locally reinvented terminal widgets while preserving shared Scriberig behavior and strengthening terminal safety.

    Do not begin task 142 until this sheet is complete.

    2. Working Discipline¶

    2.1 Read before editing¶

    • [x] Read root and design/AGENTS.md.

    2.2 Checklist discipline¶

    • [x] Keep this sheet open while implementing.
    • [x] Tick a checkbox only after exact implementation plus focused verification.
    • [x] Tick immediately; never bulk-check.
    • [x] Revert any invalidated checked item.
    • [x] Document material owner/name differences before adapting instructions.
    • [x] Review all checked items before Complete.

    2.3 Architectural prohibitions¶

    Do not:

    • perform storage/query/change logic directly from a view;
    • parse database rows in the TUI to infer semantic structure;
    • authorize an action because the palette contains its label;
    • generate semantic diff from terminal text when a semantic diff API exists;
    • turn source projection editing into direct file writes;
    • treat confirmation as permission/validation;
    • optimistically advance canonical snapshot IDs in UI state;
    • emit untrusted ANSI/OSC terminal sequences;
    • enable upstream native plugins or image protocols;
    • replace shared model/profile/preferences with TUI-local equivalents.

    Task 139's reusable kit is used for palette filtering and stable selection, the Explorer list, external text, safe Markdown, main and overlay composer editing, and semantic theme colors. Scriberig continues to own key/event normalization, modal state, domain view models, action identifiers, capability availability, and effect execution. The former fabricated change-review diff and locally duplicated session hierarchy palette were removed from the renderer. Change review now retains the exact candidate snapshot and shared before/after revision deltas, and the rendered review exposes those identities instead of listing only entity IDs.

    The public RenderedProjection result supplies projection identity, semantic scope/revision, base snapshot, style, renderer, and bytes, but has no universal source-path or synchronization fields. The project adapter carries its source path as an adapter-owned render-context extension, which is shown as projection metadata and never used as entity identity. The TUI shows synchronization as “not reported by renderer” instead of inferring that the source is synchronized. Stale-base failures and reconciliation conflicts continue through the shared operation/review error models; the TUI blocks confirmation for any conflict or validation state other than Passed. The current projection renderer is read-only; editing is a separate shared candidate operation.

    Auxiliary rendering now sanitizes overlay/context/composer text at the final Ratatui boundary, sanitizes explorer labels and kinds, and sanitizes session labels. Projection content is sanitized when the shared rendered result is adapted. The regression fixture exercises ESC/CSI, OSC 8, OSC 52, BEL, long text, malformed Markdown, and a hostile explorer row. Kit tests cover wide Unicode, clipboard policy, images disabled, and safe Markdown. The TUI suite covers minimum dimensions, keyboard reachability, exact historical selections, candidate validation/conflicts, and operation state. Focused final verification passes cargo test -p scriberig-tui (219 tests), cargo test -p scriberig-tui-kit (15 tests), cargo check -p scriberig-tui, and cargo clippy -p scriberig-tui --all-targets -- -D warnings. cargo fmt --all was also run. The full workspace gate remains deferred until tasks 138–143 are complete.
