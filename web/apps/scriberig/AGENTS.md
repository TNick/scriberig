# Integrated Web Application

This directory contains the complete browser editor and is an AGPL product surface.

The application must consume semantic behavior and transport through public `@scriberig/*` packages. It may compose MUI components and product-specific layout, but it must not import server/database internals or bypass migration/application operations for writes.

The editor should eventually combine raw knowledge-tree browsing, semantic views, projections, history/diffs, sessions/branches, operations, and agent commands around the shared selection model.
