# Material UI Package

`@scriberig/components-mui` is the opinionated MUI presentation layer. It may depend on MUI plus public Scriberig web packages, but it must not reimplement semantic caching, selection, command resolution, event handling, migration logic, or transport.

Keep reusable MUI components here rather than in the integrated app when they can serve third-party consumers. MUI usage itself is not an AGPL boundary; this package remains reusable platform infrastructure.
